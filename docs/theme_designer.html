Vending Theme Designer

Works offline from this file. Edit the colours for every screen at once, or pick one screen and give it its own colours. Previews use the firmware's own coordinates and fonts on a 320 × 240 panel.

What the new component colours change in the firmware
  • Custom theme: Config.h now offers Blossom, Ocean Blue, Mint Fresh and Custom (3). Custom reads every colour from custom_theme.h, which Save config writes from this page.
  • Every part of the UI now has its own colour macro in Core_03_Theme.ino: 119 component colours (buttons, header, cards, switches, steppers, tabs, tables, keyboard, price text, messages and more), on top of the 11 base colours.
  • Each component colour is linked to a base colour by default, so the 3 built-in themes look exactly as they did. COL_BG_TOP no longer drives button labels, headers or switch knobs on its own.
  • Unlink a component by changing its colour. Unlinked colours are written as hex values in the saved config; linked ones point to their base colour. ↺ links it back.
  • Price text (COL_PRICE_TEXT) is separate from the button colour. Buttons have their own fill, label, border, shadow and disabled colours.
  • The QR code stays black on white. Changing that would stop payments scanning.
  • A few spots that only mimic the background gradient still use COL_BG_TOP and COL_BG_BOTTOM, and the RFID status message keeps COL_TEXT_DIM.
